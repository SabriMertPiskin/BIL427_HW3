# BIL427 HW3 - ERC-20 Enerji Paylaşım DApp'i

Bu proje, BIL427 dersi 3. ödevi kapsamında geliştirilmiştir. Projenin temel amacı, Ethereum blockchain üzerinde özel bir ERC-20 token'ı oluşturmak ve bu token'ı kullanarak tüketicilerin üreticilerden enerji satın almasını sağlayan merkeziyetsiz bir uygulama (DApp) geliştirmektir.

ödevde belirtilen isterler bonuslarla beraber sağlanmıştır rapor ve screenshotlar reponun içinde yer almaktadır. Demo videosunda testleri yapılmaktadır.

Demo videosu:https://www.youtube.com/watch?v=8j9rVOFfFPc

Teknolojiler

* **Solidity:** Akıllı kontrat geliştirme dili.
* **OpenZeppelin:** Güvenli ve standartlara uygun (`ERC20`, `Ownable`, `ERC20Burnable`) kontratlar için kütüphane.
* **Truffle:** Kontrat derleme, test ve dağıtım (deployment) çatısı.
* **Ganache:** Yerel Ethereum test ağı.
* **React:** Frontend arayüzü için kullanılan JavaScript kütüphanesi.
* **Ethers.js:** Frontend'in blockchain ile etkileşimi (cüzdan bağlama, kontrat fonksiyonlarını çağırma) için kullanılan kütüphane.
* **MetaMask:** Cüzdan entegrasyonu ve işlem onayı için kullanılmıştır.
